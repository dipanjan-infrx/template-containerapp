# {{PROJECT}} — Container App service

> Generated by the **InfuCareRx Project Provisioner**. You just write code and push.

This is a tiny FastAPI service that runs as an **Azure Container App**. The
platform already wired up everything around it: the registry, the container
environment, secret storage (Tier 3), passwordless deploy auth (OIDC), and the
CI/CD pipeline.

## You only do two things

1. **Write code** in `app/`.
2. **Push to `main`.**

That's it. On every push:

| Stage | What happens | Gate |
|-------|--------------|------|
| **build** | image built and pushed to Azure Container Registry | — |
| **dev**   | deployed to the Container App automatically | none |
| **prod**  | the *same image* is promoted | ✋ **requires manual approval** |

## Run it locally

```bash
pip install -r requirements.txt
ENVIRONMENT=local uvicorn app.main:app --reload --port 8000
# http://localhost:8000  → "Fax Assigner — running in local"
# http://localhost:8000/health
```

## How config works (no secrets in code)

The app reads `ENVIRONMENT` from an environment variable — never hardcoded. For
real secrets, use the project's **Azure Key Vault** (provisioned for Tier 3) and
inject them as env vars; do not commit secrets.

## 🤖 Issue Fix Bot (open an issue → get a PR)

This repo ships with an **Issue Fix Bot**. Open a GitHub issue describing a bug or
small change, and automatically:

1. The bot comments **"on it"** on your issue.
2. **Claude Sonnet (hosted on Azure)** reads the codebase + issue and proposes a
   minimal fix and a test.
3. The bot pushes a `bot/fix-issue-<n>` branch, runs `pytest`, and opens a
   **pull request** (`Closes #<n>`) — ready for your review/approval.
4. It updates the issue comment with the PR link and test results.

You review and merge the PR if it looks right. The bot only writes inside
`app/` and `tests/`. (Powered by `.github/workflows/issue_bot.yml` +
`scripts/issue_bot.py`; the platform sets the Azure-Claude secrets for you.)

## What you do NOT manage

Infrastructure, registry, OIDC credentials, and the approval gate are owned by
the platform. Ask the platform team to change tiers or add components.
